# Windrise Bridge 常见问题排查（小白版）

> 遇到问题先看这里：按「现象」找到对应条目，照着「怎么办」一步步做。
> 每条都写了「为什么」，方便你判断问题出在哪一环。

---

## 先搞懂：整条链路是怎么连起来的

```
Notion AI ──(外网)──> 隧道地址（https://xxx/mcp/xxxx） ──> 你电脑上的 Windrise Bridge ──> 浏览器窗口 / 本机工具
```

- **Windrise Bridge**：你电脑上运行的应用，负责真正干活（开网页、操作窗口等）。
- **隧道**：把你电脑上的 Bridge 暴露成一个外网能访问的 https 地址。Notion 的服务器在外网，只能通过这个地址找到你的电脑。
- **Notion 连接（自定义 MCP 服务器）**：在 Notion「设置 → 连接」里登记这个地址，Notion AI 才能调用 Bridge。

**三段任何一段断了，都会出问题。** 排查时按顺序检查：Bridge 在不在运行 → 隧道通不通 → Notion 里登记的地址对不对。

---

## 一、连接 Notion 相关

### 1. 添加连接时，「验证」下拉里没有「无」，只有 Bearer token / Basic / API Key

**为什么**：在 Notion 里粘贴地址后，Notion 会马上用它自己的服务器去「试连」这个地址（按钮上会显示「正在加载…」）。
- 试连成功、对方不要求登录 → 出现「无」；
- 连不上 / 超时 / 地址不对 / 对方要求鉴权 → Notion 认为需要凭据，**只给需要填凭据的选项，不给「无」**。

所以**没有「无」= Notion 连不上你填的地址**，问题出在地址或隧道，不是 Notion 改版。

**怎么办**：
1. 确认 Windrise Bridge 正在运行（托盘有图标，面板能打开）。
2. 在面板里看隧道状态是不是「已连接」，复制**最新**的地址（临时隧道每次重启都会换地址）。
3. 隧道刚建好时，等 30～60 秒再填（新地址需要一点时间才能从外网访问）。
4. 检查地址是否完整：末尾那串随机码不能少、不能是旧的。
5. 在 Notion 里点「取消」，重新粘贴地址，等「正在加载…」消失后再看「验证」下拉。
6. 用面板的「一键连接 Notion」会自动做上面的检查和重试。

> 注意：试连是 **Notion 的服务器从外网访问**，不是你的电脑。`localhost`、`127.0.0.1`、局域网 IP 一律不行；本机浏览器能打开也不代表 Notion 能连上。

### 2. 之前连好的「Windrise Bridge」连接不见了

**为什么**：隧道地址变了以后需要更新连接。旧版脚本是「先删旧连接、再加新地址」，如果新地址恰好连不上（见第 1 条），就会两头都没了。新版已改成「先确认新地址能连通 → 先加新的 → 成功后再删旧的」。

**怎么办**：确认隧道正常后，在面板里重新点「一键连接 Notion」即可。

### 3. 「一键连接」提示找不到「添加连接」/ 说没有权限

**为什么**：
- Notion「设置 → 连接」页面有两个子标签「浏览连接 / 管理」，停在「管理」页时看不到「添加连接」。
- 工作区管理员可能关闭了自定义 MCP 服务器：「设置 → 连接 → 管理 → 管理权限 →『启用自定义 MCP 服务器』」。
- 免费计划或成员权限不够时，部分入口会显示「升级」。

**怎么办**：
1. 手动点一下「浏览连接」标签，再重试。
2. 让工作区管理员打开「启用自定义 MCP 服务器」。
3. 仍不行就按面板里的「手把手」提示手动添加（地址 + 验证选「无」）。

### 4. 「一键连接」卡在登录

**为什么**：脚本使用的是面板里选中的那个账号窗口，这个窗口还没登录 Notion。

**怎么办**：在弹出的 Notion 窗口里正常登录（邮箱验证码 / Google 都可以），登录完成后脚本会自动继续；或者在面板的账号下拉里换一个已登录的账号。

## 二、隧道相关

### 5. 隧道报「CHANNEL_LOCKED：「Cloudflare 命名隧道」还没有开通：未登录」

**为什么**：命名隧道（固定地址）需要先登录授权才能用，当前账号未登录或未开通。

**怎么办**：先用「临时隧道」（trycloudflare，免登录，但每次重启地址会变）；或者登录后再启用命名隧道。

### 6. 隧道地址打开是 530 / 打不开 / ERR_CONNECTION_CLOSED

**为什么**：
- 530：隧道进程已经停了，或地址已作废（临时隧道重启后旧地址立即失效）。
- 打不开：隧道刚建立还没生效；或本机开了代理软件（例如 198.18.x.x 这类「fake-ip」模式），本机访问被代理拦截——**这不一定代表外网也不通**。

**怎么办**：在面板里重启隧道，复制新地址；等 30～60 秒；仍不行就暂时关闭代理的「增强模式 / TUN」再试。

### 7. 多开浏览器页右上角显示红色「● 失败」

**为什么**：这是隧道 / 桥的状态标识，红色表示**隧道打通失败**（最常见就是第 5 条的命名隧道未开通），并不是浏览器窗口坏了。

**怎么办**：回到面板首页查看隧道的具体报错，按第 5、6 条处理。

## 三、浏览器窗口 / 分屏相关

### 8. 弹出一个带 File / Edit / View 菜单的窗口，显示「Your browser is not compatible with Notion」

**为什么**：网页里点了会「开新窗口」的按钮（如「打开 Notion」），旧版没接管这种情况，Electron 弹出原生窗口并使用自带的浏览器标识（带「Electron」字样、Chrome 版本 128），Notion 判定浏览器过旧。

**怎么办**：已在新版修复——普通新标签链接直接在当前格子打开；真正的登录弹窗会隐藏菜单并使用正确标识。若还遇到，重启 Windrise Bridge 确认是新版。

### 9. Google 登录提示「此浏览器或应用可能不安全」

**为什么**：浏览器标识里带了 Electron / 应用名，Google 会拒绝。新版已自动去掉。

**怎么办**：重启应用；仍不行就改用邮箱验证码登录。

### 10. 国内打不开 Notion / Google

**为什么**：账号窗口默认「跟随系统代理」。系统代理没开或代理规则不覆盖这些网站时打不开。

**怎么办**：打开系统代理；或在账号设置里单独填代理地址（如 `http://127.0.0.1:7890`）。

## 四、快速自检清单

| 检查项 | 正常表现 | 不正常时看 |
|---|---|---|
| Bridge 在运行 | 托盘有图标、面板能打开 | 重新打开应用 |
| 隧道状态 | 面板显示「已连接」，非红色「失败」 | 第 5、6、7 条 |
| 地址是最新的 | 和面板里复制的一致 | 第 1、6 条 |
| Notion 能试连 | 「验证」下拉里有「无」 | 第 1 条 |
| Notion 连接存在 | 设置 → 连接 →「Connected」标签里有「Windrise Bridge」（「浏览连接」里看不到） | 第 2、3 条 |
| 账号窗口已登录 | 打开是 Notion 工作区而不是登录页 | 第 4 条 |

> 新遇到的问题，请按「现象 / 为什么 / 怎么办」的格式补充到这里。
