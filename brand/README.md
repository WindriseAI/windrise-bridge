# Windrise Bridge 品牌素材（2026-10-25）

## 图标：云风筝

云就是那只风筝，在天上飞；一根线拉下来，连着你的电脑。意思是：AI 在哪都能飞，线始终拴在你自己的电脑上。

浅蓝玻璃 + 白色哑光，光从左上来，线（白色）是全图最亮的东西。不用橙色，不用紫色。

| 文件 | 用在哪 |
|---|---|
| `windrise-bridge-icon.svg` | 母版（完整光影），48 像素及以上都从它出 |
| `windrise-bridge-icon-small.svg` | 16–32 像素专用：单独重画的白色剪影，不要拿母版缩 |
| `windrise-bridge-mark-mono.svg` | 单色标记，没有底板，屏幕镂空；印刷、压印、单色场景用，改 fill / stroke 换色 |
| `export/icon-{16…1024}.png` | 各尺寸 PNG（透明圆角） |
| `export/windrise-bridge.ico` | Windows 多尺寸图标，内含 16 / 20 / 24 / 32 / 48 / 64 / 128 / 256，小尺寸用的是小尺寸版 |
| `export/favicon-32.png`、`export/apple-touch-icon.png` | 网站用 |
| `export/og.png` | 分享卡片 1200×630 |

重新导出：`python -I brand/export.py`（用本机 Chrome 渲染母版，再用 Pillow 缩尺寸；Chrome 用临时目录里的独立配置，不碰日常用的 Chrome）。分享卡片改 `og.html` 后用同样的方法截图。

## 颜色

| 名字 | 色值 | 用途 |
|---|---|---|
| 天蓝底 | `#f4f9fe` | 页面底色 |
| 白 | `#ffffff` | 哑光面、卡片 |
| 浅一档 / 浅两档 | `#e6f1fc` / `#d3e7fa` | 同一块地面上的层次 |
| 墨蓝 | `#0f2a44` | 文字、深色区块 |
| 次要文字 | `#3f5975` | 说明文字（在天蓝底上对比度够） |
| 按钮蓝 | `#1f6fc4`（悬停 `#175aa3`） | 行动按钮、链接，配白字 |
| 图标蓝 | `#3d97e8` | 小尺寸图标底色、云形圆点 |

## 字体

Inter（拉丁字母和数字）+ 思源黑体（中文），和软件界面一致。官网上的思源黑体按页面用到的字裁过，改文案后要重新裁（见 `site/README.md`）。
